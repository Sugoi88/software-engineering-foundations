Labs 01–03 remain in their existing folders. The exercises preserve the curriculum's progression from individual concepts to a complete read → validate → parse → classify → store → write workflow. Modules and imports are the next topic.

Use Python 3; no third-party packages are required. Run each exercise from its own lab directory, particularly Lab 06, whose file paths are relative to the current working directory. See the lab READMEs for examples and limitations.
