# Lab 04: Functions and Refactoring

**Status: Complete**

The eight `functions_practice` exercises cover parameters, dictionary access, return values, reusable classification and display functions, and coordinating those functions in a ticket-processing loop.

The final exercise, `functions_practice-8.py`, separates `classify_ticket()`, `display_ticket()`, and `process_tickets()`.

Run from this directory:

```sh
python3 functions_practice-8.py
```

The three sample tickets receive HIGH, MEDIUM, and LOW priority. Thresholds vary between exercises as part of the practice.
